# 補助ドキュメント

質問への回答のうち、複数のレッスンで役立つ説明をここに残します。レッスン固有の疑問は、そのレッスンの `README.md` に「理解メモ」として追記します。

新しい文書は `topic-name.md` のような分かる名前にし、次の内容を短くまとめます。

1. 元の疑問と、最初に知るべき結論
2. Blender の用語やデータ関係を使った説明
3. 小さな確認手順と期待される結果
4. 関連レッスンへのリンク

必要なら Blender バージョンや動作確認日を明記します。関連するレッスンからもここへリンクし、答えを見つけやすくします。
