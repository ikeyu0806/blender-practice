# Blender モデル開発ロードマップ

## 到達点

人物、モンスター、背景を、自分で設計・制作・修正・書き出しできるようになる。最終的には Blender のデータ構造と Python API を理解し、再実行可能な制作スクリプト、再利用できる道具、品質を確かめる手順まで自分で作れる状態を目指す。

この表はレッスンの設計図と実装状況。✅の回はスクリプトとREADMEを用意済み。[レッスン一覧](../../lessons/README.md)から開ける。番号順に終えることより、各段階の完成条件を満たし、疑問が出たらその場で扱うことを優先する。

最初は **Blender の世界だけ**で形、配置、マテリアル、複数部品の組み立てを学ぶ。Unity 連携は背景の小作品まで作れた後の選択レッスンに置く。最初から Unity の用語を前提にしない。

## 学び方

1. 各レッスンの README で「何を予測し、どこを見るか」を読んでからスクリプトを実行する。知らない言葉は [Blender 用語集](../glossary.md) で確認する。
2. 実行後に Outliner、ビューポート、ログを見て、**Object / データブロック / Transform** のどれが変わったか説明する。
3. 値を1つだけ変えて再実行する。予測と結果が違えば、理解メモを残す。
4. 4〜7レッスンごとに小作品を作る。模写だけで終えず、色・形・比率などを自分で1つ変える。
5. 詰まったときは前提のレッスンに戻るか、疑問を質問する。回答は該当レッスンの README または [補助ドキュメント](../notes/README.md) に記録する。

1レッスンは原則として**主概念1つ、観察できる結果1つ、変更実験1つ**に絞る。制作物を完成させる回では、複数の既習概念を組み合わせてもよい。画面操作を学ぶ場合も Python のデータ API と何が対応するかを確認し、UI 操作とスクリプトの両方を使えるようにする。

この回は実装済みの選択レッスン。Blender 内で複数部品のモデルを組めた後に取り組む。BlenderでFBX書き出しと再取り込みを確認済みで、Unity側は各自の環境で手動確認する。Unity を使わず Blender の人物制作へ進んでもよい。連携方法と形式は追加時の Unity / Blender バージョンで確認する。人物の骨やアニメーションの持ち込みは、人物制作後に別途扱う。[連携の補助メモ](../notes/blender-unity-import.md) も参照。

## レッスンを追加するとき

「次のレッスンを追加して」「UV 展開を学びたい」のように依頼する。既存レッスンと前提を見て、[レッスンの作成規約](../../lessons/README.md) に沿って **`lessons/<番号>_<テーマ>/lesson.py` と `README.md` を一緒に追加**する。題材に応じて他のファイルが必要なら同じフォルダに置く。実行できる環境では Blender のバックグラウンド実行で確認し、まとまりごとに Git commit する。

質問はまず会話で答え、その知識を該当レッスンの README に追記する。複数レッスンに関わる内容や Blender の一般概念は [docs/notes](../notes/README.md) に独立した文書を作り、関連レッスンからリンクする。
