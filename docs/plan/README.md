# Blender モデル開発ロードマップ

## 到達点

人物、モンスター、背景を、自分で設計・制作・修正・書き出しできるようになる。最終的には Blender のデータ構造と Python API を理解し、再実行可能な制作スクリプト、再利用できる道具、品質を確かめる手順まで自分で作れる状態を目指す。

この表は**今後追加するレッスンの設計図**。現時点で実装済みなのは [01 共有 Mesh](../../lessons/01_shared_mesh/README.md) のみ。番号順に全部終えることより、各段階の小さな完成物を作り、疑問が出たらその場で扱うことを優先する。

最初は **Blender の世界だけ**で形、配置、マテリアル、複数部品の組み立てを学ぶ。Unity 連携は背景の小作品まで作れた後の選択レッスンに置く。最初から Unity の用語を前提にしない。

## 学び方

1. 各レッスンの README で「何を予測し、どこを見るか」を読んでからスクリプトを実行する。知らない言葉は [Blender 用語集](../glossary.md) で確認する。
2. 実行後に Outliner、ビューポート、ログを見て、**Object / データブロック / Transform** のどれが変わったか説明する。
3. 値を1つだけ変えて再実行する。予測と結果が違えば、理解メモを残す。
4. 4〜7レッスンごとに小作品を作る。模写だけで終えず、色・形・比率などを自分で1つ変える。
5. 詰まったときは前提のレッスンに戻るか、疑問を質問する。回答は該当レッスンの README または [補助ドキュメント](../notes/README.md) に記録する。

1レッスンは原則として**主概念1つ、観察できる結果1つ、変更実験1つ**に絞る。制作物を完成させる回では、複数の既習概念を組み合わせてもよい。画面操作を学ぶ場合も Python のデータ API と何が対応するかを確認し、UI 操作とスクリプトの両方を使えるようにする。

## 学習順序

番号と名前は追加時の候補。制作中に分かりやすい粒度へ調整してよいが、既存レッスンの番号は変えない。各段階の完成条件を満たしたら次へ進む。必要なら人物・モンスター・背景の題材を入れ替えてよい。

### A｜Blender のデータと空間をつかむ（01–08）

| 番号 | テーマ | 手を動かして確認すること |
|---|---|---|
| 01 | 共有 Mesh ✅ | 1つの Mesh を2つの Object が参照する。`users` と位置を確認。 |
| 02 | Transform と親子 | Empty を親にし、local と world の座標を比べる。 |
| 03 | Collection | 所属を移しても親子関係と位置は変わらない。 |
| 04 | 木箱の組み立て | 板を配置し、地面に置きやすい origin を決める。 |
| 05 | マテリアルの入口 | Principled BSDF の色・金属感・粗さを比較。 |
| 06 | Modifier の評価 | Bevel の元 Mesh と評価後 Mesh の違いを調べる。 |
| 07 | 頂点から作る岩 | 頂点・辺・面を定義し、面の向きも確認。 |
| 08 | 小シーンの組み立て | 木箱と岩を配置し、原点・向き・スケールを Blender 内で確認。 |

**小作品・通過条件:** 木箱と岩を1つずつ置いた小さなシーンを作る。Object、Mesh、Collection、親子、Modifier の役割を、Outliner とログを使って説明できる。Blender 内で寸法と向きを確認できる。

### B｜形を意図どおりに作る（09–14）

| 番号 | テーマ | 手を動かして確認すること |
|---|---|---|
| 09 | メッシュ編集の基本 | 押し出し、ループ、面の選択を使って形を変える。 |
| 10 | 法線と面の向き | 裏面、スムーズ表示、シャープな縁を見分ける。 |
| 11 | 比率とシルエット | 参照画像から単純な形へ分解し、遠目の形を比較。 |
| 12 | UV 展開 | 面の切れ目とテクスチャの伸びを観察。 |
| 13 | テクスチャとマテリアル | 色・ラフネスの画像を使い、見え方を比較。 |
| 14 | 小物セット | 3種類の小物を同じ縮尺・命名・配置規則で作る。 |

**小作品・通過条件:** スタイルをそろえた小物3点を作る。近くで見た面の向きと、遠くから見たシルエットの両方を確認できる。UV の継ぎ目を選んだ理由を説明できる。

### C｜背景とシーンを組み立てる（15–20）

| 番号 | テーマ | 手を動かして確認すること |
|---|---|---|
| 15 | モジュラー背景 | 壁・床・柱を同じ寸法規則で接続。 |
| 16 | 地形と地面 | 高低差、通路、視線を単純形状で作る。 |
| 17 | 反復配置 | Collection Instance または Geometry Nodes で同じ資産を繰り返す。 |
| 18 | 照明と色 | 主光源、補助光、環境光で形の読みやすさを比較。 |
| 19 | カメラと構図 | 視点、焦点距離、前景・中景・背景を整理。 |
| 20 | 背景の小作品 | 入口のある小部屋か屋外の一角を仕上げる。 |

**小作品・通過条件:** 再利用できる部品で背景を作り、1枚の画像と再編集可能な `.blend` を残す。同じ部品を直したとき、どの配置に反映されるか予測できる。

### 選択レッスン｜Unity へ持ち込む（21）

| 番号 | テーマ | 手を動かして確認すること |
|---|---|---|
| 21 | Blender → Unity | 背景の小作品を FBX で書き出し、Unity に配置して寸法・向き・原点・マテリアルを確認。 |

この回は Blender 内で複数部品のモデルを組めた後に希望すれば追加する。Unity を使わず Blender の人物制作へ進んでもよい。連携方法と形式は追加時の Unity / Blender バージョンで確認する。人物の骨やアニメーションの持ち込みは、人物制作後に別途扱う。[連携の補助メモ](../notes/blender-unity-import.md) も参照。

## レッスンを追加するとき

「次のレッスンを追加して」「UV 展開を学びたい」のように依頼する。既存レッスンと前提を見て、[レッスンの作成規約](../../lessons/README.md) に沿って **`lessons/<番号>_<テーマ>/lesson.py` と `README.md` を一緒に追加**する。題材に応じて他のファイルが必要なら同じフォルダに置く。実行できる環境では Blender のバックグラウンド実行で確認し、まとまりごとに Git commit する。

質問はまず会話で答え、その知識を該当レッスンの README に追記する。複数レッスンに関わる内容や Blender の一般概念は [docs/notes](../notes/README.md) に独立した文書を作り、関連レッスンからリンクする。
