# Blender モデル制作レッスン

人物・モンスター・背景を自分で作れるようになるための、Blender と Python の練習プロジェクトです。小さな題材でデータの仕組みを理解し、徐々に作品と制作ツールへ進みます。

- [学習ロードマップ](docs/plan/README.md)：どの順に何を作り、いつ次へ進むか
- [Blender 用語集](docs/glossary.md)：画面とコードに出てくる言葉の意味
- [レッスン一覧と作成規約](lessons/README.md)：実行方法と今後の追加形式
- [補助ドキュメント](docs/notes/README.md)：レッスンをまたぐ疑問の回答

最初は [01 共有 Mesh](lessons/01_shared_mesh/README.md) から。各レッスンの README を読んでスクリプトを実行し、結果を観察してください。質問への回答も、関連する README または補助ドキュメントに残していきます。

実行環境の目安は `/Applications/Blender.app`。レッスン01は Blender 5.2.2 LTS で確認済みです（2026-09-26）。別の環境では、各 README の実行コマンドにある Blender のパスを読み替えてください。
